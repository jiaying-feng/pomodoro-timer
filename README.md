# 番茄时钟 (Pomodoro Timer)

这是一个基于 Python 和 Web 技术的桌面端番茄钟应用。本项目采用 **AI 辅助编程 (Vibecoding)** 模式开发，快速完成了从需求拆解到代码落地的过程。

## 核心功能
- 25分钟专注 / 5分钟短休 / 15分钟长休
- 深色现代 UI 界面
- 支持任务命名、暂停、重置操作

## 本地运行方式
1. 确保电脑安装了 Python。
2. 安装依赖：`pip install -r requirements.txt`
3. 运行程序：`python app.py`
*(注：如果桌面窗口环境缺失，程序会自动降级在默认浏览器中打开，容错率极高)*
