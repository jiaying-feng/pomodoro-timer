# 番茄钟 · 产品使用说明

番茄钟是一款基于 Python + Web 技术的桌面端专注计时工具，采用番茄工作法（25 分钟专注 + 短/长休息循环）。提供独立桌面窗口；若环境缺少桌面窗口依赖，会自动降级为在浏览器中打开，界面与功能一致。

---

## 一、安装

### 环境要求
- **操作系统**：Windows（仓库提供 `启动番茄钟.bat` 一键脚本）；其他平台可用命令行方式运行。
- **Python**：3.x（需已安装并加入 PATH）。
- **桌面窗口依赖**：`pywebview>=5.3`（由 `requirements.txt` 声明；Windows 通常还需 WebView2 运行时）。

### 安装步骤

**方式 A：Windows 一键启动（推荐）**
1. 下载或克隆本仓库到本地任意目录。
2. 双击根目录下的 `启动番茄钟.bat`。
3. 脚本会自动创建 `.venv` 虚拟环境、安装 `requirements.txt` 中的依赖并启动程序；首次运行需等待依赖安装完成。

**方式 B：命令行通用方式**
```bash
# 1. 进入项目根目录
cd pomodoro-timer

# 2.（可选）创建并激活虚拟环境
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行
python app.py
```

> 说明：`app.py` 会在本机随机空闲端口启动一个静态服务并加载 `web/` 目录。若 `pywebview` 不可用，程序会自动在默认浏览器打开计时界面，并显示一个提示窗口，关闭该窗口即退出。

## 二、主要功能

| 功能 | 说明 |
| --- | --- |
| 三种计时模式 | 专注 25 分钟 / 短休 5 分钟 / 长休 15 分钟，时长均可在设置中修改（1–180 分钟） |
| 专注—休息自动流转 | 默认每完成 4 个专注进入 1 次长休；开启"自动开始下一阶段"后可无缝衔接 |
| 任务命名 | 顶部"此刻"输入框可填写当前任务（最多 80 字），到点通知中会带上任务名 |
| 开始 / 暂停 / 继续 | 主按钮随状态在"开始 / 暂停 / 继续"间切换，支持空格键快捷操作 |
| 重置 / 跳过 | "重置"回到当前阶段起始时间；"跳过"直接进入下一阶段 |
| 进度环与今日统计 | 圆环展示本阶段进度，顶部显示今日已完成的专注数量（按自然日自动清零） |
| 提示音与桌面通知 | 阶段结束时播放提示音，并在授权后发送系统通知（可分别开关） |
| 设置面板 | 自定义三种模式时长、提示音、自动开始下一阶段、窗口置顶（窗口置顶仅桌面窗口生效） |
| 状态持久化 | 计时状态、任务、设置存入浏览器 localStorage；意外关闭后重新打开可恢复，跨天自动清零当日计数 |
| 桌面窗口 / 浏览器降级 | 优先以 pywebview 独立窗口运行，缺失依赖时自动降级到浏览器 |

## 三、操作流程

### 1. 启动
按"安装"章节运行程序，出现番茄钟界面（独立窗口或浏览器标签页）。

### 2. 填写当前任务（可选）
在顶部"此刻"输入框输入本轮专注要做的事，例如"写完项目周报"。内容会随计时一起保存。

### 3. 选择模式
界面底部有三个模式标签：**专注 / 短休 / 长休**，默认从"专注"开始。点击标签即可切换，切换会重置当前阶段计时。

### 4. 开始计时
点击中间的 **"开始"** 按钮（或按空格键）开始倒计时，圆环开始推进，阶段指示点出现脉冲动画。
- 再次点击（或按空格）为 **暂停**；暂停后按钮变为"继续"。
- 点击 **"重置"** 回到当前阶段满时长。
- 点击 **"跳过"** 直接进入下一阶段（专注 → 短休；长休后回到专注并把本轮计数归零）。

### 5. 阶段结束
倒计时归零后：
- 播放提示音并弹出系统通知（首次使用会请求通知权限）；
- 专注完成后自动进入短休，每完成 4 个专注进入 1 次长休，顶部"今日已完成"计数 +1；
- 若已开启"到点后自动开始下一阶段"，则立即开始下一阶段计时。

### 6. 调整设置
点击右上角 **设置（齿轮）** 图标打开面板：
- 用 `−` / `+` 按钮或直接输入数字，调整专注 / 短休 / 长休时长（1–180 分钟）；
- 勾选或取消"提示音""到点后自动开始下一阶段""窗口置顶"；
- 点击关闭按钮、遮罩或按 `Esc` 收起面板。

### 7. 退出
- 桌面窗口：直接关闭窗口即可。
- 浏览器降级模式：关闭程序弹出的提示小窗口即退出（计时状态已自动保存，下次打开可恢复）。

## 四、常见问题

- **中文路径 / 桌面窗口打不开**：确认已安装 WebView2 运行时；若仍失败，程序会降级到浏览器，功能不受影响。
- **提示音不响**：浏览器环境下请先与页面发生一次交互（如点击开始），浏览器才允许播放音频；也可在设置中确认"提示音"已开启。
- **收不到桌面通知**：需在浏览器/系统设置中允许本页面的通知权限。
- **倒计时不准**：本程序按结束时间戳计算剩余时间，切换标签页或锁定屏幕后回到前台会自动校正；计时状态保存在本地，不会因刷新而丢失。
